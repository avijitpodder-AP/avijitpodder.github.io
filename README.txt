GITHUB PAGES DEPLOYMENT
1. Create a public GitHub repository. For the cleanest URL, name it YOUR-USERNAME.github.io.
2. Upload ALL files in this folder to the repository root.
3. In GitHub, open Settings > Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Select main and / (root), then Save.
6. GitHub will publish the website and show the public URL.

CUSTOM DOMAIN
After purchasing a domain, add it under Settings > Pages > Custom domain and follow your registrar's DNS instructions.
